House palette

Deep navy. One cyan signal. Restraint.

The system runs dark-first. A near-black navy base with two surface levels and a single restrained electric-cyan accent. Status colours exist but are used sparingly. There is no neon, no gradient hero, no glow. Every screen should look like a working operational tool, not a marketing site.

Approved rules
  • → Dark surfaces hold ~92% of every screen. Accent is the spice.
  • → One accent per visual area. Never two cyan elements competing.
  • → Never gradient backgrounds. A single radial wash is allowed in the hero only.
  • → Never glow effects. Use a 1px accent hairline if separation is needed.
  • → Status colours never appear in marketing copy as decoration. Only in data.
  • → PDFs use paper + ink, not the dark theme. Calon-on-paper feels operational and serious.
